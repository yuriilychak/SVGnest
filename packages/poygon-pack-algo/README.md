# `@svgnest/poygon-pack-algo`

Rust/WebAssembly implementation of SVGnest's no-fit-polygon and genetic-algorithm calculations.

The package name intentionally keeps the existing `poygon` spelling. Its browser WASM output is consumed by `@svgnest/polygon-pack` workers.

## Commands

```sh
npm --workspace @svgnest/poygon-pack-algo run build
npm --workspace @svgnest/poygon-pack-algo run check
```
