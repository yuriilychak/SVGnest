# `@svgnest/ai-format-core`

Rust/WASM foundation for Adobe Illustrator input. It currently detects PDF-compatible and legacy EPS-based `.ai` containers; parser integration is tracked in [`docs/ai-format-plugin-plan.md`](../../../../docs/ai-format-plugin-plan.md).

```sh
npm --workspace @svgnest/ai-format-core run check
```
