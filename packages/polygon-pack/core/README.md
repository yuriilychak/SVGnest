# `@svgnest/polygon-pack-core`

Rust/WebAssembly implementation of SVGnest's no-fit-polygon and genetic-algorithm calculations.

Its browser WASM output is consumed by `@svgnest/polygon-pack` workers.

## Commands

```sh
npm --workspace @svgnest/polygon-pack-core run build
npm --workspace @svgnest/polygon-pack-core run check
```
